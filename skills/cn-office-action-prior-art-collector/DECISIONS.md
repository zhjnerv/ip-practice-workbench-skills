## 2026-11-24 台账命名与案号后置规范
- 背景：默认生成的对比文件台账若以我方案号命名或将案号置于开头，不利于按专利案件（申请号/专利名称）归档与对外/跨团队流转。
- 决定：在 [入口](SKILL.md) 输出规范中明确默认台账文件名优先使用专利申请号或专利名称，不使用我方案号；正文中若存在案号，统一置于「案卷基础信息」末尾。
- 放弃的方案：在 Python 脚本中新增硬编码的 Markdown 生成器（保持现有 JSON 数据输出与 Agent 模板渲染的解耦结构）。
- 影响与回退：仅影响 Agent 生成台账的命名与排版约束，不影响现有脚本接口与自测。
